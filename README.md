* Beauty Products Sales Analysis

*An independent data analysis project developed to track, analyze, and visualize sales performance data for beauty products across 2025 and 2026. 

 *Project Overview
The objective of this project is to evaluate year-over-year sales trends, identify revenue shifts, and conduct a detailed profit and loss analysis using Excel.

Key analysis focus areas include:
Total Revenue & Sales Analysis:Tracking cumulative performance across product lines.
* **Year-over-Year (YoY) Performance:** Evaluating sales differences between 2025 and 2026.
* **Profitability Insights:** Analyzing profit margins and identifying areas of loss. *Methodology & Formulas
To calculate the percentage growth/variance between periods, the following standard analytical formula was implemented in the dataset:

$$\text{Percentage Change} = \frac{\text{Current Sales} - \text{Previous Sales}}{\text{Previous Sales}} \times 100$$

*Excel Implementation Example:* `=SUM(I17-J18)/J18*100`

## Data Visualization
A dynamic Excel dashboard was constructed to transform raw data into actionable insights, featuring comparative charts and trend analysis views for enhanced visualization.
